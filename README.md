# 경조사비 장부 (GiftLedger) · 안드로이드 프로토타입 v0.2.0

경조사비를 주고받은 기록을 휴대폰 안에 저장하고 추가·조회·수정·삭제하는 앱입니다.
데이터 구조는 구글 시트 `GiftMoney_Ledger_Master`의 `ledger`, `events` 탭(스키마 v2)과 같습니다.

## APK 만들기 (Android Studio)

1. Android Studio를 설치하고 실행합니다.
2. **Open**으로 이 `giftledger` 폴더를 엽니다. Gradle 동기화가 자동으로 진행됩니다(처음 한 번은 몇 분 걸려요).
   - Android Gradle Plugin을 업그레이드하라는 안내가 뜨면 그대로 진행해도 됩니다.
3. 설치 방법은 둘 중 하나를 고르세요.
   - **휴대폰에 바로 설치**: 휴대폰의 개발자 옵션에서 USB 디버깅을 켜고 USB로 연결한 뒤 ▶ Run을 누릅니다.
   - **APK 파일 만들기**: 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. 완성되면 `app/build/outputs/apk/debug/app-debug.apk`가 생깁니다. 이 파일을 휴대폰으로 옮겨 열면 설치됩니다("출처를 알 수 없는 앱" 허용 필요).

요구 사항: Android 10(API 29) 이상.

## 구조

```
app/src/main/assets/index.html   ← 앱 화면과 기능 전체 (HTML/JS, 외부 라이브러리 없음)
app/src/main/kotlin/.../MainActivity.kt   ← 화면을 띄우는 껍데기 + 파일 선택/저장 연결 (Kotlin)
```

화면을 고치려면 `index.html`만 수정하면 됩니다. PC 브라우저에서 그대로 열어 미리 볼 수도 있습니다.

## 기능

| 탭 | 내용 |
|---|---|
| 기록 | ledger 목록, 검색(이름·소속·행사·메모), 받음/줌·행사 필터, 받은/준 합계. + 버튼으로 추가, 항목을 누르면 수정·삭제 |
| 행사 | events 목록과 행사별 받은/준 합계. 행사를 누르면 연결·관계·전달방법별 집계, 감사인사 남은 인원, 해당 기록 목록. 수정·삭제 |
| 사람 | 이름+소속으로 묶은 사람별 받은 합계, 준 합계, 차액. 누르면 그 사람과 주고받은 전체 기록 |
| 데이터 | 구글 시트 CSV 가져오기, CSV 내보내기(다운로드 폴더), 전체 초기화 |

입력 규칙은 시트와 같습니다: 행사·방향·이름·금액 필수, 금액과 식권은 0 이상 정수, 날짜는 YYYY-MM-DD,
감사인사는 받음 기록에만 Y/N. 같은 행사·방향·이름·소속이 겹치면 저장 전에 확인을 받습니다.
행사 이름을 바꾸면 그 행사의 기록도 함께 바뀌고, 행사를 지우면 그 행사의 기록도 함께 지워집니다(확인 후).

## 구글 시트 데이터 옮기기

1. 구글 시트에서 `events` 탭을 연 상태로 **파일 → 다운로드 → 쉼표로 구분된 값(.csv)**.
2. `ledger` 탭도 같은 방법으로 받습니다.
3. 두 파일을 휴대폰으로 옮긴 뒤 앱의 **데이터 → CSV 가져오기**에서 **events를 먼저**, 그다음 ledger를 선택합니다.
   - 머리글을 보고 어느 표인지 자동으로 알아봅니다.
   - 가져온 표의 기존 데이터는 바뀝니다(합쳐지지 않음).
   - events에 없는 행사명이 ledger에 있으면 종류 "기타"로 자동 추가됩니다.

## 데이터 저장

- 기기 안(앱 전용 저장공간)에만 저장되고 인터넷으로 나가지 않습니다.
- 앱을 삭제하면 데이터도 지워지니, 주기적으로 **데이터 → 내보내기**로 백업하세요.
- 내부 형식: `{schema_version, nextId, events[], ledger[]}`. 각 행에 앱 내부용 `id`가 붙고, 나머지 키는 시트 열 이름과 같습니다.
